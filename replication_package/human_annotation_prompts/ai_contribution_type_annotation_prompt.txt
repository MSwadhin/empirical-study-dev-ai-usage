Categories & Definitions with Examples:

1. Implementation
Definition: AI generates or implements executable code (functions, classes, modules, or full files).
Examples:
- Game code, docstrings, and comments were all created by ChatGPT.
- // ChatGPT created this eventListener.
- // Animation code was written by AI.

2. Knowledge and Concept Support
Definition: AI provides conceptual guidance, algorithmic suggestions, optimizations, or technical insights that the developer implements manually.
Examples:
- ChatGPT suggested adding indexes to improve performance.
- AI said to memoize this function to cut latency.
- Copilot thinks the null-pointer is here.

3. Artifact Generation
Definition: AI produces non-executable artifacts such as documentation, comment blocks, README stubs, or placeholders.
Examples:
- Full code comments generated by Claude.ai.
- # (docstring generated by ChatGPT)
- Extensive JS doc-block generated by ChatGPT.

4. Generic Comment and Indeterminate Actions
Definition: The comment acknowledges AI involvement, but provides insufficient detail to classify.
Examples:
- AI assisted.
- Generated by gpt-4-0125-preview.
- This file is generated by ChatGPT.

5. False Positive
Definition: AI-related terms appear, but there is no evidence of AI assistance.
Examples:
- #town, not generated by AI, due to repetition.
- # written by Claude Pageau.
