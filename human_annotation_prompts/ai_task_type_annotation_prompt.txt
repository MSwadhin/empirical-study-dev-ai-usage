You are given a code comment from GitHub repositories.

The input follows this format:
- "repo_name": owner/repo
- "comment": the actual code comment

Your job is to classify this comment into one of the categories listed below. If it does not fit any category, label it as False Positive.

Categories & Examples:

Code Implementation
Definition: AI produces new, executable artefacts such as functions, code blocks, or whole files.
Examples:
- "Game code, docstrings, and comments were all created by ChatGPT."
- "//for transparency, this method was written by claude.ai, based off of my old code which wasn't as good"
- "// ChatGPT created this eventListener."

Code Enhancement
Definition: AI proposes or produces fine-grained changes that improve performance, readability, or style.
Examples:
- "ChatGPT suggested adding indexes to improve performance."
- "# This function was assisted by ChatGPT to optimize performance"

Bug Identification & Fixing
Definition: AI pinpoints or helps to find a defect and provides or helps to develop a fix or workaround.
Examples:
- "Workaround suggested by ChatGPT to fix a null-pointer bug."
- "// THE FOLLOWING CODE HAS BEEN GENERATED BY CHATGPT TO REMOVE THE CORS ERROR WE WERE FACING EARLIER"
- "# GPT suggested this to fix error"

Testing
Definition: AI synthesises unit or integration tests, generates test cases, or helps with testing.
Examples:
- "# Unit tests written by AI Assistant."
- "# The basis for this test of the 'divide' operation is generated by ChatGPT using the manually created conv2d.py as a template."
- "// TODO: Test more cases here. This was generated by ChatGPT."

Documentation
Definition: AI creates docstrings or comments/explanations.
Examples:
- "Extensive JS doc-block generated by ChatGPT."
- "# (docstring generated by ChatGPT)"
- "// Comments generated by ChatGPT for learning purposes."

Generic Comments and Indeterminate Actions
Definition: The comment mentions AI but lacks enough context for classification.
Examples:
- "AI-generated helper"
- "Generated by gpt-4-0125-preview"
- "This file is generated by ChatGPT"

False Positive
Definition: AI tools or keywords matched partially or completely, but the comment does not indicate help or assistance taken from them.
Examples:
- "#town" (not generated by AI, due to repetition)
- "# written by Claude Pageau."

If none of the categories are applicable, it should be a False Positive.
