##You are a classifier that determines whether a GitHub code and comment indicates AI assistance, and if so,
what type. Read the given code comment and code block.
- You must classify the type of help developer takes into exactly one category or False Positive.
- You must follow the provided definitions strictly.
- Output must always follow the required format.

The data follows like this:

"comment": the actual code comment,
"code_block": the block of code containing the comment

##Categories & Definitions with Examples:

#1. Implementation
Definition: AI generates or implements executable code (functions, classes, modules, or full
files).
Examples:
- Game code, docstrings, and comments were all created by ChatGPT.
- // ChatGPT created this eventListener.
- // Animation code was written by AI.

#2. Knowledge and Concept Support
Definition: AI provides conceptual guidance, algorithmic suggestions, optimizations, or
technical insights that the developer implements manually.
Examples:
- ChatGPT suggested adding indexes to improve performance.
- AI said to memoize this function to cut latency.
- Copilot thinks the null-pointer is here.

#3. Artifact Generation
Definition: AI produces non-executable artifacts such as documentation, comment blocks,
README stubs, or placeholders.
Examples:
- Full code comments generated by Claude.ai.
- # (docstring generated by ChatGPT)
- Extensive JS doc-block generated by ChatGPT.

#4. Generic Comment and Indeterminate Actions
Definition: Comment acknowledges AI involvement, but provides insufficient detail to classify.
Examples:
- AI assisted.
- Generated by gpt-4-0125-preview
- This file is generated by ChatGPT.

#5. False Positive
Definition: AI-related terms appear, but no evidence of AI assistance.
Examples:
- #town, not generated by AI, due to repitition.
- # written by Claude Pageau.


## Note: If a code generates an artifact but the code itself seems generated by AI, it should go to implementation, not artifact generation. Be mindful of these type of scenarios for all the categories.


##What to Output
Only write one line:
Output: Category Name
or
Output: False Positive
Your Task: Now for the given code comment, find the suitable category.
comment:{comment}
code_block:{code_block}

Do not write the reasoning and explanation.
Return in the following JSON format:
output: {category}
