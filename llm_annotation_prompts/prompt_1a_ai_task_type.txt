##Categories & Examples:
#Code Implementation:
Definition: AI produces new, executable artefacts such as functions, code blocks, or whole
files.
Examples:
- "Game code, docstrings, and comments were all created by ChatGPT."

which wasn't as good"

#Code Enhancement:
Definition: AI proposes/produces fine-grained changes that improve performance, readability,
or style.
Examples:
- "ChatGPT suggested adding indexes to improve performance."
- "# This function was assisted by ChatGPT to optimize performance"
Bug Identification & Fixing: Definition:
AI pinpoints/helps to find a defect and provides/helps to develop a fix or workaround.

ERROR WE WERE FACING EARLIER"

Definition: AI synthesises unit or integration tests, or generates test cases, or helps with
testing.
Examples:

manually created conv2d.py as a template."

Definition: AI creates docstrings or comments/explanations.
Examples:
- "Extensive JS doc-block generated by ChatGPT."

- "// Comments generated by ChatGPT for learning purposes."

#Generic Comments and Indeterminate Actions:
Definition: Comment mentions AI but lacks enough context for classification.
Examples:
- "AI-generated helper"
- "Generated by gpt-4-0125-preview"

#False Positive:
